# geotessera: no longer used by process_viewport.py's own pipeline (VQTessera,
# below, is the standard client there now) -- kept for the coverage-probe
# endpoint (api/views/viewports.py) and scripts/tee_evaluate.py, both of which
# use it directly. Pinned to a commit on main (PR ucam-eo/geotessera#357,
# merged 2026-08-13) rather than PyPI: that PR switches embedding downloads
# to source.coop (fronted by Cloudflare, notably faster) and adds v1.1/v2
# dataset-version support -- confirmed working end-to-end against a real
# viewport bbox (registry.load_blocks_for_region + fetch_embedding, all of
# v1/v1.1/v2). Not yet released to PyPI (still 0.9.0 there as of this pin) --
# switch back to a plain PyPI floor once a release is cut.
geotessera @ git+https://github.com/ucam-eo/geotessera.git@2a52eefcb07988129df2e48cfa5abd694e58b75c
# Tessera VQ bolt-on client (VQTessera) -- the standard embeddings client for
# every viewport (process_viewport.py, api/embeddings_provider.py,
# api/views/postcard.py), not an opt-in fast path. See docs/architecture.md
# and api/embeddings_provider.py. v0.3.2 trims core deps to numpy + affine;
# everything else (Flask, sklearn, pandas, …) is behind extras
# tessera-vq[server] / [sweep] which TEE doesn't need — only the client
# surface is used.
tessera-vq @ git+https://github.com/sk818/tessera-vq.git@v0.6.4
# tessera-eval: habitat/land-cover classifier evaluation on Tessera embeddings.
# Its own repo (extracted from this tree); used by lib/evaluation_engine,
# scripts/tee_evaluate, and the tee-compute server. Deliberately fetches via
# plain geotessera (full precision), not VQTessera -- see docs/features.md §14.
# The [server] extra pulls in flask/waitress/requests (tee-compute itself)
# plus geotessera + tessera-zarr-utils (its embedding-fetch path) -- these are
# NOT in tessera-eval's base dependencies, so plain `tessera-eval` (no extra)
# silently omits flask and tee-compute fails on a genuinely fresh install.
tessera-eval[server] @ git+https://github.com/ucam-eo/tessera-eval.git@v1.5.3
